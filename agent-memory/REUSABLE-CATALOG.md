# SEO Boost Reusable Asset Catalog (cross-project)

> Catalog of assets one SEO Boost project built that ANOTHER project can replicate,
> integrate, or learn from. Lives in `agent-memory/` (shared, version-controlled,
> symlinked into every project). Read before building from scratch; add an entry
> when you finish something reusable. See skill `seoboost-cross-project-reuse`.
>
> **Bar:** technique + location only. NEVER secrets, tokens, or client/PII data.
> **Reuse mode:** `replicate` (copy+adapt) | `integrate` (call live) | `pattern` (copy approach).
> Push needs operator confirmation (Iron Law #4).

work, not inherited. Add the first entry the next time a project ships something a

## Entry template

Copy this block, fill it in, and put the newest entry at the top.

## <Asset name> (one-line what-it-is)

- **What:** what it does, in two or three sentences. Name the stack.
- **Where:** origin project + repo or workspace path. Path only — never credentials.
- **Reuse mode:** `replicate` | `integrate` | `pattern`
- **Adapt before reuse:**
  - What is hardcoded to the origin project and must be re-pointed.
  - Which numbers/labels are event- or client-specific and must NOT be carried over.
- **Status:** live in prod | shipped | prototype · **Owner:** <project> · **Added:** YYYY-MM-DD
